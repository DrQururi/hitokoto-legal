チャット日記 サポート

最終更新日: 2026年11月6日

「チャット日記」は、LINEのように1行送るだけで日記が貯まっていく、チャット風の日記アプリです。 ご質問・不具合のご報告・ご要望は、下記の連絡先までお気軽にお寄せください。 できるだけ早くお返事します。

お問い合わせ先: suraimu1285@gmail.com

よくある質問

  • データはどこに保存されますか？
    日記の内容と写真は、すべてお使いの端末の中だけに保存されます。サーバーには送信しません（アプリ改善のための匿名の利用統計だけを送ります。設定タブの「利用状況の送信」でオフにできます）。無料で提供を続けるため、カレンダーと設定の画面の下に広告を表示しますが、日記の内容は広告には渡しません。
  • アカウント登録は必要ですか？
    不要です。ログインの仕組みそのものがありません。起動したらすぐに書き始められます。
  • 機種変更でデータを移せますか？
    設定画面から日記データを JSON / Markdown で書き出せます。書き出したファイルを保管・共有してご利用ください。
  • 他の人に日記を見られませんか？
    4桁パスコードと Face ID / Touch ID でアプリをロックできます。データが外部に共有されることもありません。

チャット日記 プライバシーポリシー

最終更新日: 2026年11月6日

「チャット日記」（以下「本アプリ」）は、ユーザーのプライバシーを最優先に設計されています。 本アプリの開発・運営者（以下「運営」）は、以下の方針に基づき情報を取り扱います。

1. 収集・送信する情報について

本アプリは、日記の本文・写真など、ユーザーが入力した内容を一切収集・送信しません。 氏名・メールアドレス・電話番号・位置情報などを取得する仕組みはなく、 アカウント登録やログインの機能もありません。

別途、サービス改善のための匿名の利用統計のみ送信します（下記「3.5 利用状況の匿名計測について」参照）。 また、無料で提供を続けるため広告（Google AdMob）を表示します。広告の配信のために Google が端末の広告IDなどを取得することがあります（下記「3.6 広告の配信について」参照）。

2. データの保存先は端末内のみ

日記の本文・写真・評価・設定など、本アプリで作成したすべてのデータは、 お使いの端末の中だけに保存されます。 運営のサーバーや外部のクラウドに送信・保存されることはありません。 そのため、運営がユーザーの日記の内容を見ることはできません。

3. 写真へのアクセスについて

日記に写真を添付する機能のために、端末の写真ライブラリへのアクセスを求める場合があります。 選択された写真は本アプリ内（端末内）にのみ保存され、外部に送信されることはありません。

3.5 利用状況の匿名計測について

本アプリは、サービス改善のため、匿名の利用統計（アプリの起動・利用時間・日記を書いた回数などの機能利用回数）を収集します。 収集する情報は、イベント名・利用時刻・セッション長・アプリのバージョン・OSのバージョン・ アプリ初回起動時に生成する匿名のインストール識別子（乱数）に限られます。 お名前・連絡先などの個人を特定する情報、日記の本文・写真、位置情報は一切含みません。 この識別子は端末情報や広告識別子とは無関係で、広告には使用しません。 収集は設定タブの「利用状況の送信」からいつでもオフにできます。

3.6 広告の配信について

本アプリは、カレンダー画面と設定画面の下にバナー広告を表示します（日記を書く画面には表示しません）。 広告の配信には Google LLC の広告サービス「Google AdMob」を利用しており、 広告の配信・効果測定・不正防止のために、Google が次の情報を取得・利用することがあります。

  • 端末の広告ID（IDFA）：「トラッキング」の許可をいただいた場合のみ取得されます
  • IPアドレス、おおよその地域（IPアドレスから推定されるもので、正確な位置情報ではありません）
  • 端末の種類・OSのバージョン、広告の表示・タップなどの操作情報

日記の本文・写真・評価など、本アプリに記録した内容は、広告配信事業者に渡しません。 広告の内容区分は13歳以上向けに設定しています。

初回起動時に、お住まいの地域によっては広告に関する同意の確認画面が表示され、続いて「トラッキング」の許可確認が表示されます。 許可しなくても、本アプリの機能はすべてご利用いただけます（許可しない場合は、お好みに合わせない広告が表示されます）。

同意・許可は、次の方法でいつでも変更・撤回できます。

  • iPhoneの「設定」→「プライバシーとセキュリティ」→「トラッキング」で、本アプリのスイッチをオフにする（広告IDを使ったトラッキングの撤回）
  • iPhoneの「設定」→「プライバシーとセキュリティ」→「Appleの広告」で、「パーソナライズされた広告」をオフにする
  • 同意の確認画面が表示される地域では、本アプリの設定タブ「広告のプライバシー設定」から同意を変更・撤回する
  • Google の広告設定（https://adssettings.google.com/）で、パーソナライズ広告をオフにする

Google による情報の取り扱いについては、 Google のプライバシーポリシー（広告パートナーによるデータの利用） をご覧ください。

4. 第三者提供

日記の内容など個人のデータを収集・送信しないため、第三者への提供は行いません。ただし、上記「3.6 広告の配信について」のとおり、広告の配信のために Google が広告ID・IPアドレス等を取得します。

5. データの削除

日記や評価は、アプリ内からいつでもユーザー自身が削除できます。 アプリを削除すると、端末内に保存されたすべてのデータも削除されます。

6. ポリシーの変更

本ポリシーは予告なく変更される場合があります。重要な変更がある場合はアプリ内またはこのページでお知らせします。

7. お問い合わせ
