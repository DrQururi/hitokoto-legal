「チャット日記」は、LINEのように1行送るだけで日記が貯まっていく、チャット風の日記アプリです。 ご質問・不具合のご報告・ご要望は、下記の連絡先までお気軽にお寄せください。 できるだけ早くお返事します。

お問い合わせ先: suraimu1285@gmail.com

よくある質問

  • データはどこに保存されますか？
    すべてお使いの端末の中だけに保存されます。サーバーには一切送信しません。
  • アカウント登録は必要ですか？
    不要です。ログインの仕組みそのものがありません。起動したらすぐに書き始められます。
  • 機種変更でデータを移せますか？
    設定画面から日記データを JSON / Markdown で書き出せます。書き出したファイルを保管・共有してご利用ください。
  • 他の人に日記を見られませんか？
    4桁パスコードと Face ID / Touch ID でアプリをロックできます。データが外部に共有されることもありません。

チャット日記 プライバシーポリシー

最終更新日: 2026年10月2日

「チャット日記」（以下「本アプリ」）は、ユーザーのプライバシーを最優先に設計されています。 本アプリの開発・運営者（以下「運営」）は、以下の方針に基づき情報を取り扱います。

1. 収集・送信する情報について

本アプリは、ユーザーの個人情報を一切収集・送信しません。 氏名・メールアドレス・電話番号・位置情報などを取得する仕組みはなく、 アカウント登録やログインの機能もありません。広告は一切使用していません。

別途、サービス改善のための匿名の利用統計のみ送信します（下記「3.5 利用状況の匿名計測について」参照）。

2. データの保存先は端末内のみ

日記の本文・写真・評価・設定など、本アプリで作成したすべてのデータは、 お使いの端末の中だけに保存されます。 運営のサーバーや外部のクラウドに送信・保存されることはありません。 そのため、運営がユーザーの日記の内容を見ることはできません。

3. 写真へのアクセスについて

日記に写真を添付する機能のために、端末の写真ライブラリへのアクセスを求める場合があります。 選択された写真は本アプリ内（端末内）にのみ保存され、外部に送信されることはありません。

3.5 利用状況の匿名計測について

本アプリは、サービス改善のため、匿名の利用統計（アプリの起動・利用時間・日記を書いた回数などの機能利用回数）を収集します。 収集する情報は、イベント名・利用時刻・セッション長・アプリのバージョン・OSのバージョン・ アプリ初回起動時に生成する匿名のインストール識別子（乱数）に限られます。 お名前・連絡先などの個人を特定する情報、日記の本文・写真、位置情報は一切含みません。 この識別子は端末情報や広告識別子とは無関係で、広告目的のトラッキングは行いません。 収集は設定タブの「利用状況の送信」からいつでもオフにできます。

4. 第三者提供

日記の内容など個人のデータを収集・送信しないため、第三者への提供は行いません。

5. データの削除

日記や評価は、アプリ内からいつでもユーザー自身が削除できます。 アプリを削除すると、端末内に保存されたすべてのデータも削除されます。

6. ポリシーの変更

本ポリシーは予告なく変更される場合があります。重要な変更がある場合はアプリ内またはこのページでお知らせします。

7. お問い合わせ

本ポリシーに関するお問い合わせは suraimu1285@gmail.com までご連絡ください。
